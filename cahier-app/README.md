# Cahier

Application scolaire numérique prête pour Vercel.

## Mise en ligne

1. Décompressez le ZIP.
2. Importez le dossier dans Vercel.
3. Conservez les réglages automatiques et cliquez sur **Deploy**.

Cette version est une démonstration interactive : les données sont conservées dans le navigateur. Pour obtenir de vrais comptes synchronisés et une IA connectée capable d’analyser les images, il faudra ensuite relier un service d’authentification, une base de données et une API d’intelligence artificielle.
